# Data Transformation Library

Практична робота №8

Варіант 1: Data Transformation Library

Виконав: Савельєв Михайло, АЛК-43

## Опис

Бібліотека функцій вищого порядку для трансформації даних, реалізована з використанням принципів функціонального програмування.

## Реалізовані функції

### myMap()

Власна реалізація функції map.

### myFilter()

Власна реалізація функції filter.

### myReduce()

Власна реалізація функції reduce.

### compose()

Композиція функцій справа наліво.

### pipe()

Композиція функцій зліва направо.

### curry()

Каррінг довільної функції.

### partial()

Часткове застосування функції.

### memoize()

Кешування результатів обчислень.

### chain()

Підтримка chainable API.

## Приклад запуску

```bash
node demo.js
```
